# Focus Forest — GitHub Pages website

This folder is ready to publish with GitHub Pages.

## Included files

- `index.html` — website home page
- `privacy-policy.html` — Google Play privacy policy page
- `terms.html` — terms of use
- `contact.html` — contact page using `jamusman23045@gmail.com`
- `styles.css` — responsive site styling
- `script.js` — automatically updates the footer year
- `404.html` — fallback page

## Publish with GitHub Pages

1. Create or open a GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After GitHub publishes the site, use this URL in Google Play Console:

   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/privacy-policy.html`

## Important verification before publishing

The privacy policy assumes the current Focus Forest build:

- does not require an account;
- has no developer-operated backend or cloud sync;
- has no advertising SDK;
- has no analytics SDK;
- stores settings and progress locally on the device.

Update the policy and Google Play Data safety answers if any SDK, permission, or data-handling behavior changes.
